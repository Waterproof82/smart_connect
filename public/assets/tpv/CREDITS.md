Conversion pipeline used for every file below: the source image was
downloaded from Unsplash's CDN with an on-the-fly WebP export
(`?auto=format&fit=crop&w=1400&h=1050&q=82&fm=webp`), which is functionally
equivalent to `cwebp -q 82 -resize 1400 1050 in.jpg -o out.webp` — no
in-repo build dependency was added (design.md F3).
