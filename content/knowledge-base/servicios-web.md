## Qué ofrecemos

Digitaliza Tenerife hace páginas web personalizadas para negocios locales: restaurantes, bares, cafeterías y tiendas. No se trabaja con plantillas genéricas; cada proyecto se adapta al negocio y a sus necesidades.

## Cómo pedir presupuesto

El precio de una página web depende del tipo de proyecto y de su complejidad. Para pedir presupuesto hay que contactar en https://digitalizatenerife.es/#contacto.

## Tipos de proyecto web

Lo que incluye una página web depende del tipo de proyecto que se solicite. Hay dos tipos:

- Página web personalizada: se diseña a medida del negocio e incluye el hosting y el mantenimiento. Se entrega en un plazo de entre una semana y diez días.
- Proyecto estándar de carta digital y tienda digital: incluye una landing page de presentación con la descripción del local, sus datos y el enlace a sus reseñas de Google; acceso de contacto por WhatsApp; y un catálogo con todo el sistema de compra y envío a domicilio. También incluye el hosting y el mantenimiento.

## Ventajas de tener la web con Digitaliza Tenerife

Tener la web con Digitaliza Tenerife te ahorra ocuparte del mantenimiento y de las actualizaciones, y también te ahorra varios pagos por separado de hosting y de posicionamiento SEO. Además, te da la garantía de tener a una persona física en Tenerife que da la cara ante los clientes.

## Plazo de entrega de una página web personalizada

Una página web personalizada se entrega en un plazo de entre una semana y diez días, con el hosting y el mantenimiento incluidos.
