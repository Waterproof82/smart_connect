## Qué ofrecemos

Digitaliza Tenerife hace páginas web personalizadas para negocios locales: restaurantes, bares, cafeterías y tiendas. No se trabaja con plantillas genéricas; cada proyecto se adapta al negocio y a sus necesidades.

## Cómo pedir presupuesto

El precio de una página web depende del tipo de proyecto y de su complejidad. Para pedir presupuesto hay que contactar en https://digitalizatenerife.es/#contacto.
